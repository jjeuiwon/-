원대원 v1.4.4 온라인 업데이트

변경 사항
1. 온라인 매치에서 라운드 종료 후 한 명만 '다음 라운드'를 눌렀다면 '상대 기다리는 중…'이라고 표시합니다. 양쪽 플레이어가 모두 누른 뒤에만 다음 라운드 원 선택 화면이 열립니다.
2. 다음 라운드마다 양쪽 플레이어가 보유 원 중 무작위 두 개를 받고, 각각 하나를 다시 선택한 뒤 둘 다 선택을 마치면 배틀이 시작됩니다. 이 흐름은 매 라운드 반복됩니다.
3. 배틀 공간을 넓히고 원 크기와 이동 속도를 조금 키웠습니다.

GitHub에 업데이트하기
1. ZIP 파일을 다운로드하고 압축을 풉니다.
2. GitHub 저장소의 기존 circle_duel.html과 server.js를 각각 새 파일로 교체합니다.
3. 나머지 파일(package.json, render.yaml)은 그대로 두어도 됩니다.
4. 두 파일을 모두 저장하고 Commit changes를 누릅니다.
5. Render의 Deploys에서 배포가 Live가 될 때까지 기다린 뒤 게임 주소를 새로고침하세요.

중요: 이번 업데이트는 브라우저 게임 파일뿐 아니라 온라인 라운드 대기 절차를 처리하는 server.js도 변경합니다. 두 파일 모두 교체해야 합니다.
